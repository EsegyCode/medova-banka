# Features (Medova Banka)

Purpose: complete list of user-facing and technical features evidenced by the repository.

## Customer-facing features

- Hero and product cards for three honey sorts.
- Lead modal and forms using name, phone, honey sort and consent.
- Product prices for 1 L and 3 L quantities.
- Contact channels and sticky call button.
- FAQ groups: order, quality and storage.
- Reviews placeholders, currently empty and marked as pending owner input.
- Delivery/payment, privacy, terms, cookie and site map pages.
- Cookie banner for anonymous deletion/storage use case.

## SEO and AI features

- LocalBusiness and WebSite JSON-LD in `BaseLayout.astro`.
- `SEO.astro` outputs canonical, OG and Twitter metadata.
- 10 generated OG images in `public/og/`.
- `/llms.txt` and `/llms-full.txt` generated from site, product, FAQ and gallery data.
- Sitemap and robots from `astro.config.mjs`.
- OG image cache-busting query `?v=3` in `SEO.astro`.

## Lead and consent features

- Client-side phone formatting to `+380XXXXXXXXX`.
- Consent checkbox required before submission.
- Honeypot `company` field hidden with CSS clip.
- Mock mode driven by `PUBLIC_LEAD_MOCK=true`.
- `/api/lead` serverless function:
  - JSON parsing and validation;
  - name length 2–80;
  - phone regex `+380` + 9 digits;
  - consent required;
  - honeypot returning fake success;
  - Telegram notification unless secrets are missing.

## Technical features

- Shared `BaseLayout.astro` injects SEO and JSON-LD.
- Page route list generated by sitemap.
- Article/product schema absent; local business and website schema present.
- Google Analytics script in `SEO.astro`.
- Static cache-friendly asset pattern from Astro.
- `npm run check` for Astro type checks.

## Configuration touchpoints

- Site variables: `src/data/site.ts`.
- Products: `src/data/products.ts`.
- FAQ: `src/data/faq.ts`, with group IDs `order`, `quality`, `storage`.
- OG generation: `scripts/generate-og.mjs`.
