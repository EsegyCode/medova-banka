# SEO and AI Readiness (Medova Banka)

Purpose: document SEO, structured data and AI-facing files.

## Metadata

`SEO.astro` emits title, description, canonical, robots, Open Graph and Twitter tags. OG image URLs include `?v=3` so `SEO.astro` cache busts asset changes.

## Structured data

`BaseLayout.astro` injects:
- LocalBusiness schema with contact, address, business hours and sameAs Telegram.
- WebSite schema with Ukrainian language.
- Additional `schema` passed by a page.

## Sitemap and robots

Sitemap is generated by Astro with URL filters removing privacy, terms, cookies, oferta and llms paths from production output.

## AI files

- `/llms.txt` generated by `src/pages/llms.txt.ts`.
- `/llms-full.txt` generated by `src/pages/llms-full.txt.ts`.
- Both include site identity, product, FAQ and legal content.

## Dynamic OG images

- `scripts/generate-og.mjs` outputs ten PNG cards.
- `public/og/` contains pre-rendered assets; Astro copies them to `dist/`.

## Cache notes

Frontend uses hardcoded `?v=3` cache-busting in `SEO.astro`; change it deliberately when OG images change. TODO (owner): document an automated version scheme if needed.

## Touchpoints

- Page canonical path and noindex: `BaseLayout` and `SEO.astro`.
- Domain and sitemap: `astro.config.mjs` and `site.ts`.
- llms endpoints: `src/pages/llms*.txt.ts`.
